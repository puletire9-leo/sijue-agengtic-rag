# 开发工作流

## Volume 挂载：代码修改即时生效

后端和前端代码通过 volume 挂载，修改后**无需重建镜像**，重启容器即可：

```yaml
volumes:
  - ../backend:/app/backend    # Python 代码修改 → 重启容器生效
  - ../frontend:/app/frontend  # HTML/CSS/JS 修改 → 刷新浏览器生效
  - ../data:/app/data          # 上传文件、BM25 状态持久化
```

- **前端修改**：刷新浏览器即可
- **后端修改**：`docker restart supermew-backend`
- **新增依赖**：需要重建镜像

## 快速加依赖（开发阶段）

不想等镜像重建时，直接往容器装：

```powershell
docker exec supermew-backend pip install python-pptx -i https://pypi.tuna.tsinghua.edu.cn/simple
```

⚠️ 但容器重启后丢失。**确认依赖稳定后，写入 requirements.txt 并重建镜像。**

## 工作流建议

```
日常开发：
  改代码 → 重启容器 / 刷新浏览器 → 验证

新增依赖（临时验证）：
  docker exec pip install xxx → 验证功能

新增依赖（固化）：
  写入 requirements.txt → docker compose build python-base backend → docker compose up -d backend
```

## 依赖安装加速

在 Dockerfile 中使用国内镜像源：

```dockerfile
RUN pip install --no-cache-dir -r requirements.txt \
    -i https://pypi.tuna.tsinghua.edu.cn/simple \
    --default-timeout=120
```

- `-i https://pypi.tuna.tsinghua.edu.cn/simple` — 清华 PyPI 镜像
- `--default-timeout=120` — 防止大包下载超时

